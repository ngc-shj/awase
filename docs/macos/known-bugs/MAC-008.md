# MAC-008: 英数を押すたびに、対になる Down の無い英数の KeyUp が OS に届く

**症状:** Engine 活性中に 英数（左親指 = IME 切替キー）を押すと、OS に英数が
Down・Up・Up と届く。ATOK の切替は成功しており実害は観測されていない
（2026-10-05〜06 のログで約 30 回、毎回）。

```
12:00:14.403 phys 0x66 KeyDown LeftThumb -> consume
12:00:14.504 Engine deactivated (... reason=Inactive(ImeOff))
12:00:14.506 inj-tap 0x66 KeyDown
12:00:14.508 inj-tap 0x66 KeyUp
12:00:14.537 phys 0x66 KeyUp LeftThumb -> pass   ← 2 回目の Up
```

**真因:** 切替の期待で Engine が非活性化すると、`release_pending_and_reinject` が
保留中の親指を `Key`（Down）、保留出力の解放で `KeyUp` を送る。同時に
`flush_pending_key_ups` が「KeyUp も消費する」義務を捨てるため、物理の KeyUp は
非活性の Engine を素通りする。

**修正:** 解放で同じ VK の `KeyUp` を既に送った押下だけ、消費の義務を残す
（`src/engine/engine.rs::release_pending_and_reinject`）。それ以外の押下は従来どおり
`ReinjectKey` で KeyUp を補う。

**テスト:** `the_physical_key_up_of_a_switch_key_sent_on_deactivation_is_consumed`
（修正前は物理の KeyUp が素通しで落ちることを確認済み）。

関連: MAC-003（非活性化でも切替キーを送る）、MAC-006（Down/Up の扱いの維持）。
